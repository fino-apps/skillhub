# SkillHub 前端页面设计

面向在本机管理自有和第三方 Skill 的用户。首页用来找 Skill、导入文件夹和保存版本到本机。查看说明、检查更新、比对和整理放到详情。数据与接口约定见[技能库架构方案](SKILLHUB_ARCHITECTURE.md)。

## 1. 沿用 Fino 页面形式

- 沿用现有 Fino 页眉。保留天鹅 Logo、SkillHub 名称、API Console、Issues、Monitor、Logs、Trace 和主题切换。业务页面都渲染在同一个 `AppLayout` 下。
- 正文沿用 `skillhub-shell`，维持 1100 px 的内容上限和现有留白。首页结构为「标题与导入 → 搜索与筛选 → 列表」。工具操作用现有弹窗，较长的 Skill 说明和版本列表用独立详情页。
- 沿用 Fino 字体、亮暗主题和语义变量。页面标题沿用 26 px，列表正文 14 px、表头 13 px；输入框和工具栏按钮沿用 36 px。列表用细分隔线，主按钮沿用主题强调色，来源和分类用低对比度标签，版本号用等宽字体。状态通过「默认」「待补齐」等明确文字表达。
- 首屏业务文案只保留「技能库」、搜索筛选和按钮标签。说明文字只在操作需要时出现，例如空库、导入错误或待补齐版本。

## 2. 技能库首页 `/`

点击 Skill 名称进入详情。每行最显眼的是名称和一行用途，其余信息按来源、归类和版本顺序排列。

```text
[fino] SkillHub    API Console  Issues  Monitor  Logs  Trace       [主题]

技能库                                    [导入文件夹] [导入 GitHub] [⋯]

[ 搜索名称、用途或标签                     ] [全部来源 ▾] [全部分类 ▾] [标签 ▾]

    Skill / 用途                 来源       分类 / 标签       默认版本
□   code-review                 GitHub     开发 · Review     a1b2c3d4   保存到本机 ⋯
    审查变更并整理问题
□   release-check               本机目录    发布 · CI         87ef12ab   保存到本机 ⋯
    检查发布前的构建和配置

                               [加载更多]
```

| 区域 | 设计 |
| --- | --- |
| 导入 | 「导入文件夹」为主按钮，「导入 GitHub」为次按钮。「导入 ZIP」放入导入区的更多菜单，供收到压缩包时使用。 |
| 筛选 | 搜索名称、用途和标签。来源、分类、标签可以组合，分类包含「未分类」。搜索框有可访问的文字标签，激活筛选后提供「清除筛选」。使用服务端筛选，筛选变更重置分页。 |
| 行信息 | 名称为链接，短用途显示在其下。来源显示 GitHub、本机目录或 ZIP；来处明确的 ZIP 显示来源，详情保留导入方式。分类和少量标签同行，溢出用 `+N`，完整值可在详情查看。 |
| 默认版本 | 显示短 commit 或短摘要。快照缺失时显示「待补齐」，提供进入详情处理的入口。 |
| 行操作 | 「保存到本机」直接导出默认版本。更多菜单放「另存到…」「编辑整理信息」「下载 ZIP」和「删除」。每行只保留一个常用操作，其他动作按需展开。 |
| 多选 | 表头复选框只选择已加载的结果。选中后显示「已选 X 项」「设置分类」「修改标签」，接入后增加「AI 整理」。用户改变筛选条件时清空选择。 |

列表用已有分页游标和「加载更多」。将关键词、来源、分类和标签保存在 URL。由列表进入详情再返回时恢复筛选和滚动位置。窄屏把次要列折叠到每条的元信息中，保留名称、用途、来源和「保存到本机」，完整版本信息从详情查看。

## 3. 详情 `/skills/:skillId`

详情页沿用同一内容栏。顶部显示返回技能库的入口、Skill 名称、一行用途、来源和默认版本。右侧为「保存到本机」和更多操作。Tab 区为「概览」「版本」「文件」。

```text
‹ 技能库

code-review                                            [保存到本机] [⋯]
审查变更并整理问题
GitHub · owner/repo · skills/code-review      默认 a1b2c3d4

概览      版本      文件
          ━━━━
                                                [检查更新] [比对版本]
a1b2c3d4   默认        2026-11-03                      保存到本机 ⋯
d4e5f6a7               2026-10-21                      保存到本机 ⋯
```

| 区域 | 设计 |
| --- | --- |
| 概览 | 显示用途、分类、标签、来源及仓库链接。使用「编辑整理信息」弹窗修改用途、分类、标签和备注。下方渲染当前查看版本的 `SKILL.md`，沿用项目 Markdown 样式。 |
| 版本 | GitHub 来源提供「检查更新」，本机来源提供「保存新版本」。列表显示短标识、保存日期、备注和默认状态。每行可保存到本机，更多菜单含「设为默认」「另存到…」「下载 ZIP」「复制安装命令」「删除版本」。选择版本查看文件时明确显示正在查看的版本；标题区的保存操作始终取默认版本。 |
| 文件 | 按相对路径显示当前查看版本的文件，选中后显示可预览文本。二进制只显示文件信息。版本切换同步更新概览说明和文件列表。 |
| 版本比对 | 复用现有比对面板。顶部选择「基准版本」与「对比版本」，检查更新时预选默认版本与候选版本。左侧列出文件增删改，右侧显示选中文件的差异。窄屏将文件列表移到差异上方并使用统一视图。 |

## 4. 常用操作与反馈

| 操作 | 页面行为 |
| --- | --- |
| 导入文件夹 | 点击后打开系统目录选择器。单个有效 Skill 直接入库并显示「已导入」；多个候选才弹出勾选列表。同名时询问保存到已有条目或新建。取消系统选择后回到原页面。 |
| 导入 GitHub | 弹窗先显示一个仓库或目录 URL 输入框，分支、标签、commit 和目录补充项收在展开区。预览显示实际 commit 和候选，确认后收录；失败时保留输入并支持重试。 |
| 保存到本机 | 按钮显示「保存中…」，成功后在页面内提示路径并可复制。默认保存位置沿用架构约定。导出失败时提供「重试」或「另存到…」。 |
| 编辑和删除 | 保存期间保留表单草稿。删除确认显示 Skill 名或版本号；删除默认版本前提示先改选。 |
| AI 整理 | 从多选工具栏或「未分类」筛选下触发，开始前显示处理范围。生成时展示进度，完成后用「现有值 → 建议」的对照列表展示用途、分类、标签。每条可修改和勾选；「应用选中建议」只写入确认的项。AI 未配置时在触发处显示配置入口，手动整理照常可用。 |

首次加载在表格区域显示短状态，重新筛选保留界面宽度。空库显示「还没有 Skill」和「导入文件夹」；筛选无结果显示「没有匹配的 Skill」和「清除筛选」；读取失败保留筛选并提供「重试」。对话框沿用原生 `dialog`，关闭后焦点回到触发按钮；图标菜单和复选框提供可读名称，保存结果通过状态区域播报。

## 5. 参考项目与实现落点

| 参考 | 在 SkillHub 的用法 |
| --- | --- |
| shadcn/ui Data Table | 参考搜索筛选、行菜单和复选批量操作。使用现有语义表格和 Fino 控件实现这些交互。 [Data Table](https://ui.shadcn.com/docs/components/base/data-table) |
| ClawHub | 参考 Skill 详情中集中展示 `SKILL.md` 和历史版本的做法。 [ClawHub](https://github.com/openclaw/clawhub#what-you-can-do-with-it) |
| GitHub Compare | 借鉴基准、对比两端和文件变更导航。直接复用仓库已有的 `compare-panel.tsx` 与 npm 依赖 `react-diff-viewer-continued`。 [GitHub Compare](https://docs.github.com/en/pull-requests/how-tos/commit-changes/comparing-commits) · [差异组件](https://github.com/Aeolun/react-diff-viewer-continued) |
| React Router | 沿用现有路由、懒加载和 `useSearchParams`。详情可直接打开，列表筛选可随 URL 恢复。 [React Router](https://reactrouter.com/api/hooks/useSearchParams) |

项目页继续维护在 `frontend/app/`。首页收敛为列表和筛选，详情承载文件、版本及整理。复用现有 `local-intake.tsx`、`github-intake.tsx`、`skill-metadata.tsx`、`version-panel.tsx` 和 `install-command.tsx`。新增业务样式并入 `skillhub.css`。目录选择、保存到本机、版本和 AI 使用架构规划的接口，调用以 Fino 生成契约为准。

页面实施时先走通「导入文件夹 → 查找 → 保存到本机」和「导入 GitHub → 查看版本 → 比对」。再接入多选整理和 AI。验收覆盖明暗主题、桌面与窄屏、键盘操作、长名称换行、返回时筛选恢复，以及空库、无匹配、失败和待补齐状态。
